# 激光牙科机器人控制系统 - 接口文档（最终优化版）
基于OpenAPI 3.0规范，结合实际代码实现逻辑，对齐接口路径、参数、响应格式，从**准确性、一致性、实用性**维度优化，确保文档与代码1:1匹配。

## 文档基础信息
| 项          | 内容                                                                 |
|-------------|----------------------------------------------------------------------|
| 文档版本    | v1.0.1（代码对齐版）                                                 |
| 接口前缀    | 核心前缀`/api/v1`（部分历史接口前缀为`/api`/`/v1`，已标注）          |
| 基础域名    | 开发环境：`http://localhost:8080`<br>生产环境：`https://api.laserdentalrobot.com` |
| 认证方式    | JWT（请求头携带 `token: {token}`，非标准Bearer格式，代码实际使用`token`头） |
| 响应格式    | JSON（统一返回体 `Result`）                                          |
| 限流规则    | 所有接口10秒内最多5次请求                                            |
| 跨域支持    | 仅允许前端 `http://localhost:5173` 访问                              |

## 通用响应结构体
### Result（全局统一返回格式）
```json
{
  "code": 200, // 响应码：200成功，其他为失败（400/401/403/404/429/500）
  "msg": "操作成功", // 响应信息（失败时为错误描述）
  "data": {} // 业务数据（可选，成功时返回具体内容，失败时为null）
}
```

### 通用错误码说明
| 响应码 | 错误码标识       | 描述                     |
|--------|------------------|--------------------------|
| 400    | PARAM_ERROR      | 请求参数错误/格式非法    |
| 401    | UNAUTHORIZED     | 未授权（Token无效/缺失） |
| 403    | FORBIDDEN        | 权限不足/账号被封禁      |
| 404    | NOT_FOUND        | 资源不存在（用户/模型等）|
| 429    | TOO_MANY_REQUESTS| 请求频率超限             |
| 500    | SERVER_ERROR     | 服务器内部错误           |

## 接口模块详情（代码对齐版）

### 一、用户管理模块
#### 1. 用户注册
- **接口路径**：`/api/user/register`（代码实际路径，无v1前缀）
- **请求方法**：POST
- **请求头**：`Content-Type: application/json`
- **请求体（RegisterRequest）**：
  | 字段名   | 类型   | 必填 | 描述         | 示例     |
  |----------|--------|------|--------------|----------|
  | username | String | 是   | 用户名       | user01   |
  | password | String | 是   | 密码（明文） | 123456   |
- **请求示例**：
  ```json
  {
    "username": "user01",
    "password": "123456"
  }
  ```
- **响应示例（成功）**：
  ```json
  {
    "code": 200,
    "msg": "注册成功",
    "data": null
  }
  ```
- **响应示例（失败）**：
  ```json
  {
    "code": 400,
    "msg": "用户名已存在",
    "data": null
  }
  ```
- **异常场景**：
  - 400：用户名/密码为空、用户名已存在
  - 500：注册插入数据库失败

#### 2. 用户登录
- **接口路径**：`/api/user/login`（代码实际路径，无v1前缀）
- **请求方法**：POST
- **请求头**：`Content-Type: application/json`
- **请求体（LoginRequest）**：
  | 字段名   | 类型   | 必填 | 描述         | 示例     |
  |----------|--------|------|--------------|----------|
  | username | String | 是   | 用户名       | admin    |
  | password | String | 是   | 密码（明文） | 123456   |
- **请求示例**：
  ```json
  {
    "username": "admin",
    "password": "123456"
  }
  ```
- **响应体（LoginVO）**：
  | 字段名   | 类型    | 描述                     | 示例                                  |
  |----------|---------|--------------------------|---------------------------------------|
  | token    | String  | JWT令牌（直接返回，非Bearer） | eyJhbGciOiJIUzI1NiJ9...               |
  | id       | Long    | 用户ID                   | 1                                     |
  | username | String  | 用户名                   | admin                                 |
  | role     | Integer | 角色（0-普通用户，1-管理员） | 1                                     |
- **响应示例（成功）**：
  ```json
  {
    "code": 200,
    "msg": "登录成功",
    "data": {
      "token": "eyJhbGciOiJIUzI1NiJ9...",
      "id": 1,
      "username": "admin",
      "role": 1
    }
  }
  ```
- **异常场景**：
  - 400：用户名/密码为空、密码错误
  - 404：用户不存在
  - 403：账号被封禁

#### 4. 分页查询用户列表（管理员）
- **接口路径**：`/api/admin/user/list`（代码实际路径，非v1前缀）
- **请求方法**：GET
- **请求头**：`token: {token}`
- **请求参数（Query）**：
  | 字段名   | 类型    | 必填 | 描述         | 示例 |
  |----------|---------|------|--------------|------|
  | pageNum  | Integer | 否   | 页码（默认1） | 1    |
  | pageSize | Integer | 否   | 每页条数（默认10，最大100） | 10   |
- **响应体（PageResult<UserEntity>）**：
  | 字段名    | 类型      | 描述                     | 示例 |
  |-----------|-----------|--------------------------|------|
  | list      | List      | 用户列表（不含密码）     | 见示例 |
  | total     | Long      | 总条数                   | 1    |
  | pageNum   | Integer   | 当前页码                 | 1    |
  | pageSize  | Integer   | 每页条数                 | 10   |
  | totalPages| Integer   | 总页数                   | 1    |
- **响应示例**：
  ```json
  {
    "code": 200,
    "msg": "操作成功",
    "data": {
      "list": [
        {
          "id": 1,
          "username": "admin",
          "role": 1,
          "status": 1
        }
      ],
      "total": 1,
      "pageNum": 1,
      "pageSize": 10,
      "totalPages": 1
    }
  }
  ```
- **异常场景**：
  - 401：Token缺失/无效
  - 403：非管理员角色
  - 400：页码/每页条数非法

## 补充说明
1. **JWT校验规则**：
   - 代码中实际使用`token`请求头（非`Authorization: Bearer {token}`）
   - 仅管理员接口/用户信息接口做权限校验，其余接口无校验
2. **密码安全提醒**：当前代码中用户密码为明文存储/比对，生产环境需替换为BCrypt加密；
3. **限流触发**：请求频率超过10秒5次时，接口返回429，提示“请求过于频繁，请稍后再试”；
4. **跨域限制**：仅允许前端 `http://localhost:5173` 访问，生产环境需替换为实际前端域名；
5. **接口调试**：可通过Swagger UI访问 `http://localhost:8080/swagger-ui.html` 在线调试所有接口；
6. **响应格式兼容**：AI聊天模块接口响应为自定义AIChatResponse，非全局Result格式，需前端适配。
